# Courtside

A basketball discussion site built for fans who actually want to talk about the game beyond basic box scores and social media memes. It covers everything from live game threads and trade rumors to draft prospects, coaching adjustments, and debates over all-time rankings. Whether you want to break down a team's defensive rotation or just vent after a bad fourth-quarter collapse, it gives people a dedicated spot to follow the season and argue hoops with other die-hards.

API used: [TheSportsDB](https://www.thesportsdb.com/documentation)
